# Avalanche Collections — WeVibed React Website

Premium image-led React/Vite website for Avalanche Collections, based on the supplied brand logo and product photography.

## Business details used
- The Waves Plaza, 88 Central Avenue between 7th & 8th Street, Shop D, next to the Pharmacy, Harare, Zimbabwe
- WhatsApp: +263 77 257 9054
- Instagram: @avalanchecollections09 and @avalanchecollection
- Category: Women's clothing store
- In-store shopping

No product prices or stock claims are invented. Product cards direct visitors to WhatsApp for current availability, sizes and pricing.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Cloudflare Pages:
- Build command: `npm run build`
- Output directory: `dist`
- Root directory: `/`
